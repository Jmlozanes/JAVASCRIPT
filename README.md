A collection of JavaScript exercises and small applications created to improve my programming fundamentals, problem-solving skills, and understanding of JavaScript concepts.

## 📂 Projects

### 🃏 Card Counting Assistant
A JavaScript exercise that practices functions, variables, conditions, and logical operations.

Concepts:
- Functions
- Variables
- Conditional statements
- Mathematical operations


### 🏦 Loan Qualification Checker
A decision-based application that determines loan eligibility based on income and credit score.

Concepts:
- Function parameters
- If / Else If / Else
- Logical operators
- Comparison operators


### ✂️ Truncate String Tool
A string manipulation project that shortens text based on a given character limit.

Concepts:
- String methods
- Parameters
- Return values


### 📅 Leap Year Validator
A program that checks whether a given year is a leap year.

Concepts:
- Modulus operator (%)
- Conditional logic
- Boolean expressions


### 🔐 Simple Authentication
A basic validation system that checks user input.

Concepts:
- Data types
- Validation
- Boolean logic
